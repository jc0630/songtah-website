# 崧達企業官網 改版網站檔案

打包日期：2026-11-03
線上預覽：https://songtah-website.vercel.app（暫存網址，已設定不讓搜尋引擎收錄）

## 1. 這是什麼

這是崧達企業官網改版後的**完整靜態網站**：

- 全部是 HTML、CSS、JavaScript 與圖片檔，不需要資料庫，也不需要 WordPress 後台。
- 共約 310 個頁面，約 1,500 個檔案，解壓後約 118 MB。
- 網站的基礎是原本的 WordPress（Elementor）頁面，匯出成靜態檔後重新設計與改寫。

## 2. 如何在電腦上預覽

網站內的連結用的是相對路徑，用瀏覽器直接雙擊 `index.html` 也能看。但部分功能（例如字型、表單、地圖）需要在網頁伺服器上才會正常，建議用以下任一方式開啟。

**macOS / Linux（內建 Python）**

```
cd site
python3 -m http.server 8080
```

然後用瀏覽器開啟 http://localhost:8080

**或用 Node.js**

```
npx serve site
```

## 4. 改版樣式在哪裡

改版的視覺都寫在 `_theme/` 裡，蓋在原本 Elementor 的樣式之上：

| 檔案 | 用途 |
|---|---|
| `songtah-theme.css` | 全站基礎：字型、色彩、頁首頁尾 |
| `cards-apple.css` | 全站卡片樣式與大部分區塊的調整（最主要的檔案） |
| `home.css`、`home-v4.css` | 首頁 |
| `product.css`、`product-v2.css` | 產品詳細頁 |
| `story.css`、`story.js` | 崧達歷程頁與關於頁的入口區塊 |
| `cards-fx.js` | 卡片滑鼠移過時的浮凸與傾斜效果 |
| `poster-lightbox.js` | 課程海報放大檢視 |
| `workflow-steps.js` | 數位製程步驟區塊 |
| `form-mailto.js` | 聯絡表單（見第 5 節） |
| `st-track.js` | 按鈕點擊追蹤 |

頁面引用這些檔案時，網址後面會加 `?v=…` 版本號，用來避免瀏覽器使用舊的快取。

**設計規範**

- 字型：Noto Sans TC（中文）、Montserrat（英文與數字），由 Google Fonts 載入。
- 主色：品牌深綠 `#334A33`、亮綠 `#62B320`，搭配暖木色系；崧達歷程頁使用胡桃木深色底 `#1E150E`。
- 不使用進場動畫，動態只在滑鼠移過或點擊時出現。
- 各區塊在任何螢幕寬度都維持卡片格線。
